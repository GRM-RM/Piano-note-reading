## 上下文

仓库没有应用代码。第一版是给零基础用的识谱练习：固定 C 大调、只认音高、高音谱表和低音谱表都出现、用虚拟键盘作答。使用者把一个 HTML 文件发到手机，用系统浏览器竖屏打开，可以离线练习。

## 目标 / 非目标

**目标：**

- 用一个自包含的 `index.html` 完成出题、作答、纠错、出声和当前一轮统计。
- 大谱表每次只显示一个全音符，答案是具体音高（含八度），由屏幕白键点选。
- 竖屏一列布局；键盘固定为 88 键，放不下时横向滑动。
- 不依赖构建工具、外部脚本、字体或网络。

**非目标：**

- 节奏、拍号、符干、调号、升降号、黑键答案。
- 横屏专用布局，以及锁定系统方向。
- 唱名、简谱、账号、跨天成绩、曲目库、MIDI 键盘。
- 应用商店安装包或服务端。

## 决策

1. **单文件页面。** CSS、脚本和谱面绘制都放在根目录 `index.html`。手机用 `file://` 打开时，跨文件引用和模块导入经常被拦住，单文件才能稳定离线运行。

2. **谱面用页面内 SVG 绘制。** 只需要五条线、谱号和一个全音符符头，不引入制谱库，也不画拍号。大谱表始终同时显示；音符落在它所属的那一行。中央 C 在高音谱下加一线和低音谱上加一线两种写法之间随机。

3. **音高集合固定为白键。**

   | 范围 | 音 | 白键数 | 默认 |
   |---|---|---|---|
   | 中央 C 附近 | F3–G4 | 9 | 是 |
   | 只高音 | C4–F5，C4 只写在高音谱 | 11 | |
   | 只低音 | G2–C4，C4 只写在低音谱 | 11 | |
   | 全部入门 | G2–F5，C4 两种写法都可能出现 | 23 | |

   G2–B3 只出现在低音谱，D4–F5 只出现在高音谱。同一音高且同一种写法不连续出现两次。

4. **键盘是完整的 88 键。** 从 A0 到 C8，52 个白键可点，36 个黑键只作「两、三」分组的视觉参照，不可作答。白键宽度不小于 44px，因此竖屏必须横向滑动；滑动只发生在键盘区域。打开页面和切换范围时，把当前练习范围滚到可视区域中间，其余琴键仍可滑到。点到非答案白键算答错。

5. **先判对错，再出声。** 「开始」按钮恢复音频上下文。作答前禁止自动发声。点中正确白键时，用振荡器播放该音（A4 = 440Hz）。第一次点错：标出音名（如 C4）并保持正确键高亮，计时在第一次点击停止；再次点中正确键后才出声并进入下一题。黑键点击无效果。

6. **统计只在内存里。** 记录题数、首次即对的题数、首次作答的平均用时。换范围会换掉当前这道题，累计数字保留。刷新页面后清零。

7. **竖屏是唯一布局。** 范围按钮、谱表、统计、键盘从上到下排成一列，键盘留出底部安全区。视口变宽变高时仍保持这一列，不拆成左右栏。

## 风险 / 权衡

- [手机预览不执行脚本] → 页面不依赖安装步骤；使用说明写明用 Safari 或 Chrome 打开，微信内预览不可用。
- [本地页面的音频被浏览器锁住] → 用「开始」作为第一次用户操作来解锁，练习中不再自动出声。
- [88 键在竖屏上很长] → 白键保持至少 44px，只滚动键盘；切换范围时把该范围滚到中间，避免每次从 A0 找起。
- [自绘谱面在加线位置算错] → 音高、谱表和加线数量做成同一张表，渲染和判定共用它。
- [黑键盖住白键边缘] → 黑键不接收作答；白键保持最小触控宽度。

## 迁移计划

新增 `index.html` 即可使用。不需要数据迁移。撤回时删掉该文件。
