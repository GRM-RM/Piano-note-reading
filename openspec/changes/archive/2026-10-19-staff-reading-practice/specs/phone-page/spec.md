## 新增需求

### 需求:单个 HTML 可在手机浏览器离线打开
练习必须交付为仓库根目录的一个 `index.html`。样式、脚本和谱面绘制必须包含在该文件内。页面禁止请求外部脚本、样式、字体或音频文件。练习者用手机系统浏览器打开本地文件时，出题、点键和出声必须可以在无网络下完成。

#### 场景:断网仍然可以练习
- **当** 手机没有网络，并用系统浏览器打开该 HTML 文件
- **那么** 练习者可以完成至少一题的作答、纠错和出声

#### 场景:文件自包含
- **当** 检查该 HTML 文件的外部引用
- **那么** 不存在需要联网才能加载的脚本、样式、字体或音频

### 需求:竖屏单列布局
页面必须按竖屏排成一列，顺序为范围按钮、大谱表、当前一轮统计、虚拟键盘。键盘必须留出设备底部安全区。视口变宽或变高时，页面必须保持这一列，禁止改成谱表与键盘左右并排。

#### 场景:手机竖持时四块内容都可见
- **当** 练习者以竖屏打开页面
- **那么** 范围按钮、大谱表、统计和键盘按从上到下的顺序出现在同一列

#### 场景:手机被转侧后仍是一列
- **当** 视口宽度大于高度
- **那么** 谱表和键盘仍然上下排列

### 需求:键盘显示完整钢琴并可滑动
键盘必须显示标准钢琴的 88 个键（A0 到 C8），其中 52 个白键可点，36 个黑键可见且禁止作为作答目标。每个白键的宽度必须不小于 44px。白键总宽超过屏幕时，只有键盘区域可以横向滑动，谱面必须保持不动。切换练习范围时，键盘必须把该范围滚到可视区域中间，并继续保留其余琴键。范围切换必须使用直接点选的大按钮，禁止使用需要展开的下拉菜单。点中白键时必须有按下的视觉反馈。

#### 场景:一架完整钢琴
- **当** 练习者打开页面
- **那么** 键盘包含从 A0 到 C8 的 88 个键

#### 场景:竖屏可以左右滑动
- **当** 白键总宽超过屏幕
- **那么** 练习者可以横向滑动键盘作答，谱面不随滑动移动

#### 场景:范围按钮可直接点
- **当** 练习者要点「只高音」
- **那么** 该范围在页面上直接可见，一次点击即可切换，键盘仍是 88 个键
