# note-drill 规范

## 目的

待定。本能力规定入门识谱练习如何按范围出单音题、用白键判定具体音高、在作答之后才发声，并且只统计当前一轮。

## 需求

### 需求:按范围出单音题
练习必须在 C 大调白键中出题，每次只显示一个全音符，禁止显示符干、拍号、调号和升降号。大谱表必须两行同时可见。可选范围必须是：中央 C 附近（F3–G4）、只高音（C4–F5）、只低音（G2–C4）、全部入门（G2–F5）。默认范围必须是中央 C 附近。G2–B3 必须写在低音谱，D4–F5 必须写在高音谱。中央 C 在「只高音」中必须写在高音谱下加一线，在「只低音」中必须写在低音谱上加一线，在另外两个范围中必须在这两种写法中随机选择。同一音高且同一种写法禁止连续出现两次。

#### 场景:默认从中央 C 附近开始
- **当** 练习者点「开始」
- **那么** 第一题的音高在 F3 到 G4 之间，并画在对应的谱表上

#### 场景:切换范围会换掉当前题
- **当** 练习者从「中央 C 附近」切换到「只低音」
- **那么** 当前音符被替换为 G2 到 C4 中的一个音，已累计的题数和对错保留

#### 场景:中央 C 有两种写法
- **当** 当前范围是「全部入门」且抽到 C4
- **那么** 音符要么在高音谱下加一线，要么在低音谱上加一线，正确答案都是 C4 那个白键

### 需求:用白键判定具体音高
系统必须把正确答案定为谱上的具体音高，包含八度。只有对应该音高的白键是正确答案。其余白键必须算作答错。黑键必须可见且禁止作为作答目标。

#### 场景:首次点中正确白键
- **当** 谱上是 E4 且练习者第一次就点中 E4
- **那么** 该题记为正确，播放 E4，并自动出现下一题

#### 场景:点错后必须改正
- **当** 谱上是 C4 且练习者第一次点了 D4
- **那么** 系统标出音名 C4，正确白键保持高亮，在点中 C4 之前禁止进入下一题

#### 场景:点其他白键算答错
- **当** 谱上是 C4 且练习者点了 A0
- **那么** 该题按首次答错处理，并高亮 C4

#### 场景:点黑键没有判定
- **当** 练习者点了黑键
- **那么** 当前题保持不变，不记对错，也不发声

### 需求:作答之后才发声
作答之前禁止播放当前音。练习者必须先点「开始」，之后正确白键被点中时才播放该音。音高必须以 A4 = 440Hz 计算。答错时禁止播放练习者点错的那个音。

#### 场景:未开始时没有声音
- **当** 练习者还没有点「开始」
- **那么** 页面不播放任何音

#### 场景:改正时才听到正确音
- **当** 练习者第一次点错，随后点中高亮的正确白键
- **那么** 系统播放正确音高，然后进入下一题

### 需求:只统计当前一轮
系统必须显示已作答题数、首次即对的题数，以及首次作答的平均用时。用时必须从题目出现计到第一次点击，禁止使用倒计时。改正时的第二次点击禁止另计一题。统计必须只留在当前页面会话中，刷新后必须清零。

#### 场景:答错不增加正确数
- **当** 练习者第一次点错并随后点对
- **那么** 题数增加 1，首次即对的题数不增加，平均用时只计入第一次点击

#### 场景:刷新后统计消失
- **当** 练习者刷新页面
- **那么** 题数、正确数和平均用时回到初始值
