# 识谱练习版本功能清单

当前页面是 `app/index.html`，对应第 3 版。后一版包含前面各版的功能。

GitHub Pages 开启后，地址为 `https://用户名.github.io/仓库名/app/`。

## 第 1 版：入门识谱

零基础、C 大调、只认音高。一个 HTML 文件发到手机，用 Safari 或 Chrome 打开，可离线使用。

- 竖屏单列：范围、大谱表、本轮统计、虚拟键盘。手机转过去仍是这一列。
- 点「开始」后才出题、才出声。
- 四个范围可随时切换，默认「中央C附近」：
  - 中央C附近：F3–G4
  - 只高音：C4–F5
  - 只低音：G2–C4
  - 全部入门：G2–F5
- 大谱表每次一个全音符。G2–B3 写在低音谱，D4–F5 写在高音谱。中央 C 在「中央C附近」和「全部入门」里会在高音谱下加一线、低音谱上加一线两种写法中出现。
- 同一音高、同一种写法不连续出现两次。
- 点中正确白键进入下一题，并播放该音（A4 = 440Hz）。点错的白键不出声，标出音名，必须再点中正确键。黑键不可作答。
- 本轮统计：题数、首次即对、首次作答平均用时。换范围保留累计，刷新后清零。没有倒计时。

这一版的键盘只画出当前范围，两侧各多一个灰键。

## 第 2 版：完整键盘

- 虚拟键盘改为标准 88 键（A0 到 C8）：52 个白键可点，36 个黑键只用于辨认黑键分组。
- 白键宽度至少 44px。放不下时只左右滑动键盘，谱面不动。
- 打开页面或切换范围时，把当前练习范围滚到可视区域中间。
- 点到任何一个非答案白键都算答错。

## 第 3 版：中央 C 标记

- 只有 C4 白键下端有红点和「中央C」字样。其他八度的 C 没有这个标记。

## 当前版本功能（第 3 版）

- 单个 HTML（`app/index.html`），可离线打开，也可挂到 GitHub Pages 用 Safari 打开。
- 竖屏单列布局。
- C 大调单音练习，四个范围，大谱表全音符。
- 88 键可左右滑动，中央 C 有红点和文字标记。
- 只有点中正确白键才出声；答错须改正。
- 只保留当前这一轮的题数、正确数和平均用时。
